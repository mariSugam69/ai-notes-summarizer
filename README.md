# ai-notes-summarizer
A web-based AI application that summarizes long text or PDFs into concise summaries using Machine Learning. It includes a PDF upload option, user-friendly UI, and a backend built with Python and Flask.

🚀 Features

Summarizes long text or uploaded PDFs

Modern UI with interactive buttons

Copy summary to clipboard

Loading animation during processing

Works offline with local AI model

🛠️ Tech Stack

Frontend:
HTML, CSS, JavaScript, PDF.js

Backend:
Python, Flask, Flask-CORS, HuggingFace Transformers, PyTorch
